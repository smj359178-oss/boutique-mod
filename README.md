# بوتیک مُد | فروشگاه آنلاین لباس

فروشگاه آنلاین لباس با طراحی مدرن، پنل مدیریت کامل، تم تاریک/روشن و سفارش‌گیری از طریق واتساپ. ساخته‌شده با Next.js 16، React، TypeScript و Tailwind CSS.

## ✨ ویژگی‌ها

### فروشگاه (Storefront)
- 🏠 **صفحه اصلی** جذاب با هیرو، دسته‌بندی‌ها، محصولات پیشنهادی، بنر تخفیف و نظرات مشتریان
- 🛍️ **فروشگاه** با فیلتر کامل (دسته‌بندی، قیمت، سایز، رنگ، جستجو) و مرتب‌سازی
- 👗 **صفحه جزئیات محصول** با گالری، انتخاب رنگ و سایز، تب‌های توضیحات/مشخصات/نظرات
- 🛒 **سبد خرید** با کشیدنی Side Drawer و مدیریت تعداد
- 📱 **سفارش واتساپی** خودکار (تولید پیام فارسی + باز کردن واتساپ)
- 📞 **سفارش تلفنی** مستقیم
- ℹ️ صفحات **درباره ما** و **تماس**
- 🌗 **تم تاریک/روشن** با انیمیشن
- 📱 طراحی کاملاً **ریسپانسیو** (موبایل و دسکتاپ)
- ✨ انیمیشن‌های Framer Motion در سراسر سایت

### پنل مدیریت (Admin)
- 🔐 **ورود با رمز عبور** (پیش‌فرض: `admin123`)
- 📊 **داشبورد** با آمار فروش، نمودار درآمد ۷ روزه، نمودار دسته‌بندی، پرفروش‌ترین‌ها
- 📦 **مدیریت محصولات** (افزودن/ویرایش/حذف کامل)
- 🗂️ **مدیریت دسته‌بندی‌ها** (CRUD)
- 📋 **مدیریت سفارش‌ها** با فیلتر وضعیت و تغییر وضعیت
- ⚙️ **تنظیمات فروشگاه** (نام، شعار، واتساپ، تلفن، آدرس، شبکه‌های اجتماعی، متن‌های صفحه اصلی، رمز مدیریت)

## 🛠 تکنولوژی‌ها

- **Next.js 16** (App Router) + **React 19** + **TypeScript 5**
- **Tailwind CSS 4** + **shadcn/ui** (مجموعه کامل کامپوننت‌ها)
- **Prisma ORM** + **SQLite** (دیتابیس)
- **Zustand** (مدیریت state کلاینت + ناوبری + سبد خرید)
- **TanStack Query** (مدیریت state سرور)
- **Framer Motion** (انیمیشن)
- **Recharts** (نمودارهای پنل مدیریت)
- **next-themes** (تم تاریک/روشن)
- **Vazirmatn** (فونت فارسی)
- **lucide-react** (آیکون‌ها)

## 🚀 اجرا

```bash
# نصب وابستگی‌ها
bun install

# همگام‌سازی دیتابیس
bun run db:push

# پر کردن دیتابیس با داده نمونه
bun run scripts/seed.ts

# اجرای پروژه در حالت توسعه (پورت 3000)
bun run dev
```

سپس به `http://localhost:3000` بروید.

## 🔑 ورود به پنل مدیریت

1. روی **«پنل مدیریت»** در نوار بالای سایت کلیک کنید (یا از منوی موبایل)
2. رمز پیش‌فرض: **`admin123`**
3. رمز را از بخش «تنظیمات → امنیت» قابل تغییر است

│   │   ├── db.ts              # Prisma client
│   │   ├── store.ts           # zustand ناوبری
│   │   ├── cart.ts            # zustand سبد خرید (persist)
│   │   ├── hooks.ts           # React Query hooks
│   │   ├── types.ts           # تایپ‌ها
│   │   ├── data.ts            # helpers سرور
│   │   └── utils.ts           # فرمت قیمت، اعداد فارسی، رنگ‌ها
│   └── components/
│       ├── ui/                # کامپوننت‌های shadcn/ui
│       ├── admin/             # پنل مدیریت (login, dashboard, products, categories, orders, settings)
│       ├── views/             # صفحات فروشگاه (home, shop, product, about, contact)
│       ├── header.tsx, footer.tsx, cart-drawer.tsx, product-card.tsx, ...

## 📋 دسته‌بندی‌ها و محصولات نمونه

- **زنانه**: پیراهن مجلسی، بلوز کرپ، کاپشن زمستانی، دامن پلیسه
- **مردانه**: پیراهن آستین بلند، تیشرت، کت چرم، شلوار جین
- **بچگانه**: پیراهن دخترانه، تیشرت پسربچه
- **اکسسوری**: کیف چرم، شال، عینک، ساعت

هر محصول دارای: تصویر، قیمت، تخفیف، رنگ‌بندی، سایزبندی، برند، جنس، امتیاز و تعداد نظر.

## 🎨 طراحی

- پالت رنگی **رز/بورگوندی** شیک و مناسب فروشگاه لباس
- تم روشن با پس‌زمینه کرم گرم و تم تاریک با ذغالی عمیق
- انیمیشن‌های ظریف (ورود، hover، شناوری، marquee)
- اسکرول‌بار سفارشی، افکت شیشه‌ای (glass)، پس‌زمینه mesh
- کاملاً **RTL** و فارسی

## 📝 یادداشت

- پرداخت آنلاین فعال نیست — سفارش از طریق واتساپ یا تماس نهایی می‌شود
- شماره واتساپ و سایر اطلاعات از پنل مدیریت قابل تغییر است
- تصاویر محصولات با هوش مصنوعی تولید شده‌اند
